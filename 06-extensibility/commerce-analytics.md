# Commerce analytics

## Summary

This procedure lives on the **Docs** tab of **Commerce** inside your Birkly install. Open the **Commerce overview** topic there. That text updates when you update the plugin. This page does not repeat it.

## Beginner

**Example: open the Commerce overview topic**

1. Enable **Commerce** from **Plugins → Hub** or **Settings → Plugins**.
2. Open **Commerce** in the sidebar and select the **Docs** tab.
3. Open **Commerce overview**. Follow that article. Do not copy a `commerce-storefront.js` script tag from an old page. Commerce pages include `birkly-client.js` only.

## Advanced Users

API tables and provider settings for this topic are on the same Docs tab, under **Advanced Users**. A publish of docs.birkly.com does not change them. Update the Commerce plugin.
