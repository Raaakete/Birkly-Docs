Admin plugin extension

How plugin authors extend the Birkly admin without editing core PHP or JS. P83 mirrors the P82 storefront shelf: core aggregates manifests and registries; plugins own presentation.

Public storefront shelf: Project sites and plugins (storefront.scripts[]).

Declare admin.scripts[] in plugin.json. Register dashboard mount handlers in plugin JS. Register notification formatters and WebMCP runtime packs in PHP. Subscribe to birkly_entry_saved instead of expecting core to call plugin functions directly.

Admin asset shelf

Active plugins declare scripts in plugin.json under admin.scripts[]. Core injects tags via birkly_render_admin_script_tags() and dispatches birkly:admin-plugins-ready after load.

Dashboard widget mounts

Widget data from PHP (dashboard_widgets_callback); UI in admin/dashboard-widget.js using BirklyDashboardWidgets[mountName].

Notification platform shelf

register_notification_formatter(), register_broadcast_actor(), and birkly_plugin_activity_emit(). Full examples: 06-extensibility/admin-plugin-extension.md.

WebMCP runtime packs

birkly_webmcp_register_runtime_pack() plus assets/webmcp-pack.js. Core loops runtime descriptors; no hardcoded pack functions.
