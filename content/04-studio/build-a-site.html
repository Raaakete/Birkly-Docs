Build a site with Studio (non-developer path)

Studio is an alternative to hand-editing files in project/. You work in the admin Studio screen: pick a starter, edit pages visually, connect collections, and publish to /site/{your-slug}/.

1. Create a project

  1. Open Studio in the admin sidebar.
  2. Click New project.
  3. Choose a starter template (business, blog, portfolio, and others).
  4. Enter a name, pick a style kit, and set the site language for live content.
  5. Click Create — Studio opens the workspace.

2. Edit pages

  • Use the Pages tab on the left to switch pages, set the home page (star), reorder, or add pages.
  • Click Insert to add a section or start Connect content to show collection entries on the page.
  • Use the right inspector to change text, images (media library), and spacing.
  • Advanced (toolbar) reveals the file tree, code view, and extra binding controls.

3. Connect CMS content

  1. Click Insert → Connect content.
  2. Follow the wizard: choose a collection, filters, and ordering.
  3. Studio inserts a binding that compiles to canonical Birkly template syntax.

4. Publish

  1. Click Publish — review the preflight sheet (pages list and route health).
  2. Click Publish now when ready.
  3. Open the public URL shown in the sheet (or use Open ↗ in the toolbar for preview).

Draft preview while logged in as admin uses your session; visitors only see published projects.
