# Events plugin

## Summary

**Events** adds classes, workshops, and other dated entries to a Birkly install. Free RSVP and paid tickets are configured on the event. The full click-path lives on the plugin’s **Docs** tab inside the admin, and it updates when you update the plugin.

## Beginner

**Example: open the manual in this install**

1. In **Plugins → Hub**, install **Events** and enable it.
2. Open **Events** in the admin sidebar.
3. Open the **Docs** tab. Follow **Getting started** there: add an event field, publish one class, and open the RSVP link. That tab is the procedure. This page does not repeat it.

## Advanced Users

Registration endpoints, template helpers, and automation triggers are documented on the same Docs tab. Do not copy those requests into the public site as the owner path. A docs publish on docs.birkly.com does not change the plugin manual. Update the plugin to change it.
