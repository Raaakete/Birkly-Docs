Guide for invited closed-alpha testers of Birkly. If you do not have an invite, request access at the Birkly website waitlist.

Closed alpha means Birkly is feature-complete enough for real self-hosted trials but not a public beta. Expect rough edges. Your job: use the CMS on your own server, report bugs and ideas via in-admin Feedback, and read Help for live Birkly-Docs. We ship fixes from your reports before open beta.

Getting started

  1. Install Birkly on a server or local PHP (see Getting started).
  2. Complete onboarding (project name, first admin user).
  3. Open Help (sidebar) for contextual docs — Read full doc opens Birkly-Docs topics.
  4. Install plugins from Plugins → Hub (Commerce, Events, Automation, User Management).
  5. Connect AI under Settings → AI & Integrations — start with Ollama locally if you have no API key.
  6. Optionally link cloud account under Account (does not replace local password).

Reporting issues

Use Feedback in the admin (not only email) so we capture:

  • Your message and category (bug / idea / other)
  • Optional screenshot note
  • Page URL, CMS version, and browser info

We use this data only to improve the alpha (see Alpha legal and website Privacy Policy). Include steps to reproduce for bugs.

What not to expect yet

  • Production SLA or 24/7 support
  • Managed hosting from us — you self-host
  • Full public marketplace without QC review for verified tier
  • FX conversion between currencies (set each price explicitly)
