Import purchasable entries from CSV via Commerce → Settings → Import & migrate in admin. For a one-time Shopify move with customers and archived orders, see Shopify cutover. For live API sync (Beta), see Commerce live import.

The import wizard supports CSV upload from many platforms (WooCommerce, Shopify, Magento, and more) with preset column mapping. Choose a target collection, preview rows, and import with idempotent SKU matching. Import history supports rollback. Live REST API import (Beta) is grouped in the same Import & migrate area. Legacy Shop / Events migration appears only when those sources are detected — see Commerce migration wizard.

Beginner

Start an import

  1. Open Commerce → Settings → Import & migrate.
  2. Click Import products.
  3. Step 1 — Platform: Search or filter (Stores / Inventory) and pick your source (for example WooCommerce or Shopify CSV).
  4. Step 2 — Upload: Select target collection (existing or create new), default currency, and upload the CSV (or paste CSV text).
  5. Step 3 — Review: Check the preview table and row counts.
  6. Step 4 — Done: Confirm created/updated counts.

Export from your old store

Each platform card shows export steps. Typical paths:

  • WooCommerce: Products → Export → CSV (Name, SKU, Regular price, Stock).
  • Shopify: Products → Export → CSV (Variant SKU, Variant price, inventory qty).

Import history

Import & migrate lists past runs with status, counts, and actions:

  • Details — view created/updated breakdown.
  • Remove — rollback imported entries (optionally delete collection if the import created it).

Match existing entries by SKU or external_id column — update vs create.

Use dry-run mode (preview step) to validate rows before writing entries.

For ongoing sync without manual CSV export:

  • Commerce live import — Shopify, WooCommerce, Etsy, Square (Beta); preview and scheduled cron sync.

Out of scope (CSV v1)
