# Automation

## Summary

**Automation** runs workflows when something happens in a Birkly install: an entry changes, a schedule fires, or a webhook arrives. The click-path and the worked examples live on the plugin’s **Documentation** tab inside the admin. That tab updates when you update the plugin.

## Beginner

**Example: open the manual in this install**

1. In **Plugins → Hub**, install **Automation** and enable it.
2. Open **Automation** in the admin sidebar.
3. Open the **Documentation** tab. Follow **Getting started** and **Examples** there for a complete workflow. This page does not repeat that walkthrough.

## Advanced Users

Triggers, conditions, actions, Setup, and dry-run versus live runs are on the same Documentation tab. A publish of docs.birkly.com does not change that manual. Update the Automation plugin to change it.
