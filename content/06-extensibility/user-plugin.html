User Management adds website accounts to a Birkly install: registration, login, tiers, and collection permissions. The click-path and the {user_logged_in} template live on the plugin’s Docs tab inside the admin. That tab updates when you update the plugin.

Beginner

Example: open the manual in this install

  1. In Plugins → Hub, install User Management and enable it.
  2. Open User in the admin sidebar.
  3. Open the Documentation tab. Follow User Management for registration and the login template. Paid tiers are Membership products. Signup paths are Signup flows. This page does not repeat those walkthroughs.
Advanced users

Field types, permission keys, and the registration APIs are on the same Docs tab. A docs publish on docs.birkly.com does not change that manual. Update the plugin to change it.
